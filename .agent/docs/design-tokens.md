# Design tokens — AL DUBAI

The palette is **measured**, not chosen. Every hex below was read out of
`dd/Customer Management - AL DUBAI Admin.svg`, one of the existing brand
screens. Only colour is taken from that file; layout comes from
`specs/wireframes/`.

Machine-readable versions:
`specs/design/tokens/colors.json` · `typography.json` · `theme.css`
Generated by `.agent/scripts/design/tokens.py`.

It is a **warm neutral** palette — brown, peach, cream. Do not introduce a blue,
a violet or a grey-blue: the wireframes use teal and violet because they are
low-fidelity, and those colours are deliberately dropped in the finished design.

### Status pairs

Every status has one text colour and one surface colour, defined once in
`tokens.STATUS`, so a chip and a table cell for the same state can never
disagree. `active`, `available`, `completed`, `returned` → success.
`on rent`, `in transit` → bronze on warning surface. `reserved`, `partial`,
`repairing` → warning. `low stock`, `conflict`, `disposed` → danger.
`draft`, `released`, `cancelled`, `fulfilled`, `discontinued` → muted.

- Latin: **Inter** (shadcn's default, so nothing has to be re-specified)
- Dari and Pashto: **Vazirmatn** — see [`localisation.md`](./localisation.md)
- Mono: **JetBrains Mono**, for SKUs and barcode captions only

Money and quantities use `font-variant-numeric: tabular-nums`. A column of
afghanis that does not line up is a bug.

**Tracking is never applied to Perso-Arabic.** `svg.txt()` zeroes it
automatically.

## Shape

| Token | Value |
|-------|-------|
| card radius | 16 |
| control / input / tile radius | 12 |
| small radius | 8 |
| button, chip, avatar | fully rounded (pill) |
| card shadow | `0 1px 2px rgba(27,28,26,.04), 0 8px 24px rgba(27,28,26,.05)` |
| drawer shadow | `-24px 0 48px rgba(27,28,26,.12)` |

Buttons and chips are pills; cards and inputs are soft rectangles. That contrast
is the brand's main shape signal — keep it.

## Icons

**lucide-react** — the exact 24 × 24 stroked geometry is inlined in
`.agent/scripts/design/svg.py` (`ICONS`). Stroke 1.6–1.8, round caps and joins.
Directional icons (chevron-right, arrow-left, transfer) mirror in Dari and
Pashto; the rest do not.

## Applying it

```bash
cp specs/design/tokens/theme.css app/globals.css
```

The variable names are shadcn's (`--primary`, `--muted-foreground`, `--sidebar`
…), so every component picks the brand up without being restyled one by one.
