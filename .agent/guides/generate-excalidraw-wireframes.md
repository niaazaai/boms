# Generate Excalidraw wireframes

From repo root:

```bash
python3 .agent/scripts/generate_wireframes.py
```

Outputs overwrite:

```
specs/wireframes/mobile/*.excalidraw
specs/wireframes/desktop/*.excalidraw
```

Open any file in the Excalidraw VS Code/Cursor extension or at https://excalidraw.com (File → Open).

**Excalidraw is the only wireframe source of truth** (no markdown screen specs).
